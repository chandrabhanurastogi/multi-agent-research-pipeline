# Multi-Agent Research & Synthesis Pipeline

A multi-agent pipeline that turns an analyst question into a verified research briefing.

## Status

Architecture/design phase.

## Objective

Build a locally runnable multi-agent pipeline that takes an analyst query and produces a structured research briefing with:

- synthesized findings
- supporting evidence
- identified uncertainties
- contradiction handling
- derived confidence
- verification results

## Technology

- Python
- LangGraph
- LangChain where appropriate
- Real LLM API
- Sample research corpus
